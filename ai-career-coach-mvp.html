MVP的目标

我们不是要做一个完整产品，我们只需要验证四个核心问题。

我们要验证什么？
  1. 用户会不会因为这个痛点来找我们？（获客验证）
  2. 用户用了工具之后，会不会留下来？（需求验证）
  3. 这些用户场景能否收集到用户职业信息上下文，为生成个性化AI教练提供数据？（数据验证）
  4. 这个模式最后能不能收到钱？（商业化验证）

第一个版本，
不贪多，只验证这四个核心问题，
验证我们的闭环能不能跑通。

MVP思路

我们的MVP思路是什么？

我们采用三层递进策略，从获客到价值沉淀自然生长。

我们的MVP三层逻辑
🎣
情绪钩子
第一步：用用户会主动搜索的痛点问题击中他，让用户觉得"这说的就是我"，愿意主动点进来
🔧
工具承接
第二步：用户进来了，直接用工具解决他这个具体问题，立刻让用户感受到"有用"
💛
积累价值
第三步：用一次工具沉淀一份用户职业数据，用得越多AI越懂用户，长期的教练价值自然就生长出来了
核心本质：
工具带来频率 → 频率产生记忆 → 记忆产生情感 → 情感建立壁垒
这就是为什么我们和Character.AI那种"为聊而聊"本质不同：
• 他们靠新鲜感维持，新鲜感退去用户就走了
• 我们靠高频工具维持留存，情感是工具使用的副产品，越用越稳固

一句话总结：用户不会主动找"教练"，但会主动找"解决我这个具体问题的工具"。先用工具解决问题，再从工具生长出教练关系。
切入点选择

MVP的4个切入场景 & 为什么选它们？

我们先看完整流程，再看筛选标准，最后逐个分析。

整个MVP完整流程
环节 详细内容
获客渠道/手段 小红书/抖音/知乎/B站/脉脉做内容种草，每个切入场景对应一个痛点钩子标题，击中用户情绪，引导用户进入产品
工具承接 1️⃣ 求职全流程管理   2️⃣ 智能简历系统   3️⃣ 个人技能树管理   4️⃣ Offer决策分析
四个工具独立可用，直接解决具体问题
情感积累 每一次使用沉淀用户职业数据，AI越来越懂用户，根据用户数据慢慢养成适合用户的"性格" —— 对焦虑的用户更温暖，对理性的用户更直接，情感连接自然建立
付费引导 提供两种付费模式，满足不同用户需求：
1. 按Agent用量收费：单次深度分析/决策类服务（比如Offer深度分析）可以按次收费，适合"只解决这一次问题"的用户，不用订阅就能体验
2. 全局订阅收费：按月/按年订阅，解锁所有工具全部功能+跨工具数据同步+AI教练长期陪伴，适合需要长期使用的用户
免费版限制使用次数/保存数量，满足不了需求的用户自然转化
筛选标准：四个必须同时满足

我们选择这四个场景，因为它们同时满足了四个筛选标准：

1️⃣
单独能打
工具本身就能解决一个完整问题，用户可以为了它单独来
2️⃣
竞品短板
现有产品做得不好，或者根本没人做，我们一上来就是优势
3️⃣
能沉淀数据
用了这个工具，就能积累用户职业数据，为教练价值铺路
4️⃣
能勾住用户
本身对应一个痛点，适合内容传播获客
四个切入场景详细分析
1️⃣   求职全流程管理
解决什么痛点 今年春招太卷，投了几十份简历，用户需要同时开好几个招聘APP，看到心仪岗位没法统一保存，翻半天找不到；自己用Excel记进度，没人提醒复盘，面试完就忘了问了什么问题
竞品不足 招聘平台根本不会做：他们靠"成交"赚钱，用户找到工作就流失，没动力帮你管理全程。求职管理目前是绝对蓝海，从来没有产品做过求职全流程闭环。
情绪钩子场景 • "投了50份简历全石沉大海？试试这个方法"
• "多个招聘APP来回切，我这记性根本记不住"
2️⃣   智能简历系统
解决什么痛点 用户自己对着空白文档瞎写，不知道怎么突出亮点；找别人改要花几百块，太贵；超级简历只有模板，不会帮你梳理内容；简历写好存在硬盘，新项目做完懒得更新，投不同岗位只能凑合用
竞品不足 现有产品都是"卖模板"，没人做"跟着用户一直成长"的动态简历。大家只是给你个空模板让你自己填，不会帮你梳理成就亮点，也不会帮你同步更新到技能树。
情绪钩子场景 • "改简历要花500块？AI三分钟帮你搞定，比猎头改得还好"
• "工作三年想跳槽，简历还是校招那版怎么办？"
3️⃣   个人技能树管理
解决什么痛点 技能都存在脑子里，被裁员/想转型，不知道自己现有技能哪些能用；想转型目标岗位，不知道缺哪些技能；课程平台的技能树都是用来卖课的，不是帮你管理自己成长的
竞品不足 完全空白市场：没有任何产品帮用户管理个人职业技能成长。市面上的技能树要么是课程平台用来卖课的，要么是大厂内部用的，没有服务个人用户的成长工具。
情绪钩子场景 • "35岁被裁员，不知道自己能干什么？试试AI帮你画张技能树"
• "AI会取代我的工作吗？帮我看看风险有多大"
4️⃣   Offer决策分析
解决什么痛点 拿到多个offer，去牛客/知乎发帖问网友，每个人说法不一样，看完更纠结；没人帮你结合你的情况分析，网友都是站着说话不腰疼
竞品不足 完全空白：没人做"结合用户偏好加权打分"的个性化分析。所有的offer对比都是固定维度，不会根据你的优先级调整权重，也不会给你谈判策略和入职计划。
情绪钩子场景 • "两个offer纠结到失眠？把信息给我，AI按你的偏好帮你选"
• "HR压我薪资，怎么谈才能涨？"

四个切入点总结

每个都满足单独能打 + 竞品空白 + 沉淀数据 + 能做钩子
覆盖求职+在职全场景，从获客到沉淀一气呵成

小张 · 2026届毕业生
春招投了50份简历没几个回复，天天焦虑睡不着
看见广告钩子： 小张刷小红书，刷到标题《投了50份简历全石沉大海？试试这个方法》，瞬间被击中，这不就是我吗？赶紧点进来想试试。
AI引导过程： AI说："我知道你现在很焦虑，没关系，我们一步步来，先把你投过的岗位都整理清楚，咱们就能找到问题出在哪了。你只要把岗位链接发给我就行。" 小张跟着引导，把收藏的岗位一个个复制进来，边说自己的迷茫。
AI调用工具能力： AI自动保存所有岗位，给每个岗位打了匹配度分数，帮小张排序，还设置了面试提醒。面试完，AI主动提醒小张复盘："今天面试完了吧？我们把面试官问的问题记下来，下次遇到就不会慌了"，自动整理了所有问题。
输出高质量结果： 整理完小张一看，"没想到我投了这么多，原来还有三个岗位我忘记跟进了！" 看着整理清晰的进度表，一下子就清爽了，面试前翻一下整理好的问题，心中立刻就稳了。
共情和情绪价值： 整理完AI说："我看了你的背景，其实你学校和项目都不错，今年行情就这样，不是你不好，只是投递太分散了，我们把精力集中在匹配度高的岗位上，机会一定会来的。" 小张瞬间就鼻子一酸 —— 好久没人跟他说过这话了，一直都是自己扛着，AI一下子就说到他心里去了。
付费转化： 小张想一直保存这份进度记录，随时更新，注册了账号发现免费只能保存10个岗位，他有五十多个岗位要追踪，马上就开通了专业版 —— 这份踏实感，值。

完整流程

从获客到商业化
完整MVP全环节

从用户点击进来，到成为付费用户，再到沉淀价值，每一步怎么走。

第一步 · 外面获客
  • 每个切入点对应一个钩子标题，直接命中用户搜索的痛点问题
  • 渠道：小红书/抖音/知乎/B站/脉脉，根据场景选择
  • 内容形式：短视频/图文笔记/问答种草

举例：

  • "投了50份简历全石沉大海？" → 小红书短视频 → 落地"求职全流程管理"
  • "改简历花了我500块？" → 抖音对比视频 → 落地"智能简历系统"
  • "35岁被裁员不知道能干什么？" → 知乎问答 → 落地"个人技能树管理"
  • "两个offer纠结到失眠？" → 小红书案例 → 落地"Offer决策分析"
第二步 · 首屏承接
  • 用户点进来，不需要登录就能直接用
  • 直接解决用户当前问题，立刻给出结果
  • 用户满意了 → 想要保存结果 → 引导注册账号
第三步 · 交叉推荐
  • 用户用了A工具 → 推荐你用B/C/D工具
  • 例子：你做了offer决策 → 推荐你梳理一下技能树
  • 目标：让用户用越多工具 → 沉淀越多数据 → 越离不开我们
第四步 · 价值沉淀
  • 每一次使用都沉淀用户职业数据 → AI越来越懂用户
  • AI根据用户数据慢慢养成适合用户的"性格"
  • 当用户用了2个以上工具 → "教练"价值自然显现
  • 替代成本建立：换一个产品 = 从零开始重新沉淀 → 用户不会走
第五步 · 商业化

MVP阶段策略：先验证需求，不急于收费

  • 种子期（第一个月）：全功能免费，目的是收集用户反馈，打磨产品
  • 增长期（第二个月起）：两种付费模式
    • 按Agent用量收费：单次深度分析/决策类服务可以按次收费，适合"只解决这一次问题"的用户，不用订阅就能体验
    • 全局订阅收费：按月/按年订阅，解锁所有工具全部功能 + 跨工具数据自动关联同步 + AI教练长期陪伴，适合需要长期使用的用户
    • 免费版：每个工具限制使用次数/保存数量，满足不了需求自然转化付费
成功标志

我们怎么知道MVP成了？

MVP不是把功能做出来就完了，我们要验证这个闭环能不能跑通。

需要验证的核心指标
验证阶段 指标 目标 说明
获客验证 内容点击率 高于行业均值 说明钩子标题确实击中痛点
需求验证 匿名使用 → 留存 > 30% 说明产品确实解决了问题，用户愿意留下来
数据验证 单用户平均数据量 用了X个工具 → 沉淀Y条职业信息 说明这个场景确实能为个性化教练收集足够数据
商业化验证 免费 → 付费转化 MVP阶段不用高，有正例就算成 说明用户愿意为这个价值付钱
壁垒验证 30天留存 / 90天留存 显著高于纯AI陪伴产品 说明数据沉淀确实建立了壁垒，用户留存更高

一句话总结MVP成功

我们跑通了 "痛点获客 → 工具解决 → 数据沉淀 → 付费转化" 这个完整闭环，就是MVP成功。
之后就是在这个基础上，持续迭代增加功能，一步步做大。
